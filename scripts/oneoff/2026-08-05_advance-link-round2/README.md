## รูปแบบสคริปต์ (ตาม `.claude/rules/verification-discipline.md`)

`BEGIN IMMEDIATE` → แก้ → **assert ทุกข้อในทรานแซกชัน** → พังข้อไหน rollback ทั้งชุด
→ ค่อย `commit` → เปิด connection ใหม่อ่านซ้ำเป็นสัญญาณอิสระ
ไม่มี flag `rehearse|live` หลอกๆ — path ของ DB คือโหมด

fingerprint (sha256 ของทุกแถว) ของ `salary_advances`, `payroll_items` และคอลัมน์เงิน/
วัน/บัญชี/แท็ก ของ `cashbook_transactions` ถูกเทียบ *ในทรานแซกชัน* ก่อน commit
ถ้าอะไรที่ห้ามแตะขยับแม้แถวเดียว → rollback

  ห้ามทิ้ง `.db` ที่ไม่บีบอัดไว้ที่ `/data` root) undo จริงคือ pre-state ของ 16 แถว:
  ทุกแถว `salary_advance_id = NULL`, `category = 'เงินเดือน'` ยกเว้น ct 642 ที่เป็น
  `'เงินเดือน (เบิกล่วงหน้า)'` อยู่แล้ว
